Kimi can now operate a real browser.

In Kimi Work, the Agent browser can directly click, type, and navigate inside browser tabs tied to the conversation.

That changes the workflow. Instead of only telling you what to do, Kimi can turn a goal into browser actions.

The interesting part is the loop: understand the task, act in the browser, inspect what happened, then continue.

And Kimi's latest Agent workflow is built around exactly this kind of long-running task execution.

So Kimi is moving from answering inside a chat to actually operating the tools around it.
