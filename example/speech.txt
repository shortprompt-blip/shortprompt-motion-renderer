I gave an AI coding agent one prompt: build a playable 3D browser game from scratch.

No step-by-step implementation. Just the goal, the controls, the game loop, and one important constraint: it has to run reliably in a browser.

We follow the work through a realistic desktop workflow: the coding agent, the browser, the terminal, the project files and the final verification.

The agent first inspects the project, identifies the renderer, scene, gameplay logic and regression tests, then starts implementing.

The browser runs locally while the 3D scene and gameplay systems are connected.

Then the regression suite catches a placement edge case. The agent traces the coordinate calculation, fixes deterministic grid snapping and optimizes repeated static geometry.

The tests pass again, the production build completes and the browser preview is verified.

The interesting part is not generating a 3D cube. It is whether the agent can move through the complete engineering loop: inspect, implement, run, diagnose, fix, optimize and verify.
