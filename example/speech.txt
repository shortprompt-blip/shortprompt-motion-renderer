Kimi just released K3, and it is not a small update.

Moonshot describes it as a 2.8 trillion parameter model, with native vision and a one-million-token context window.

The interesting part is what that means in practice.

K3 is built for long-horizon work: large codebases, complex reasoning, documents, and tasks where the model has to keep context for much longer.

And Kimi is not positioning K3 as just another chatbot. The same model sits inside Kimi Code, where the company is targeting serious software development.

Today, Kimi Code lists K3 alongside K2.8 Preview and a high-speed K2.7 coding model. So the important distinction is not simply which model is newest. It is which model and context size fit the workload.

Then there is the agent side.

Kimi says K3 strengthens long-running agentic tasks, including coding workflows, terminal interaction, and large-scale parallel work through Agent Swarm.

So the real story behind K3 is not just 2.8 trillion parameters.

It is the combination: open weights, native vision, a million-token context window, coding, and agents in the same ecosystem.

That makes K3 one of the most interesting open models to watch right now.
