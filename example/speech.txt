If Claude gives you long, messy answers, the problem may be your prompt.
Here are five prompt patterns you can reuse to get better results with less wasted output.

Number one: give Claude a role and an exact output contract.
Act as a senior Python reviewer. Return only: verdict, three issues, and the smallest safe patch.

Number two: add the context that actually matters.
Explain the goal, constraints, and why the task matters before asking for the solution.

Number three: separate instructions from data with XML tags.
Use instruction, context, input, and output sections so Claude can tell what is a rule and what is source material.

Number four: show examples.
Give Claude two or three examples of the input and the output you want. This is one of Anthropic's recommended ways to steer format and consistency.

And number five: control the answer size.
Ask for the final answer only, with a strict format and a maximum number of bullets. You get the information you need without a giant response.
