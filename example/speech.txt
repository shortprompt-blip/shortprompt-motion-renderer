Want to turn a long recording into a transcript with speaker labels and word-level timestamps? In this tutorial, we’ll set up NVIDIA Nemotron 3.5 Transcribe with its official vLLM integration.

First, check your hardware. The reference BF16 setup targets one NVIDIA H100 with 80 gigabytes of memory. NVIDIA also publishes an FP8 profile for an RTX PRO 6000 Blackwell with 96 gigabytes. This is not a lightweight laptop model.

Install Git, uv, Python 3.13, and a compatible CUDA environment. Clone NVIDIA’s NeMo Speech repository, install the ASR and vLLM extras, then download the Nemotron 3.5 Transcribe checkpoint from Hugging Face.

Start the vLLM server using NVIDIA’s documented launch profile. The server exposes an OpenAI-compatible endpoint on port 8000.

Now encode a WAV recording as base64 and send it with a transcription instruction to the chat completions endpoint. Keep reasoning disabled and temperature at zero for transcription.

For speaker attribution and word timestamps, use the documented speaker-tag prompt, enable CTC timestamp capture, and keep the timestamp middleware enabled. Check the returned alignment error before using the word timings.

That’s the complete workflow: prepare the GPU environment, launch the model, send audio, and inspect the transcript. Full commands and sources are in the guide linked below.
