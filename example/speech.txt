If you use Claude for difficult coding or agentic work, choosing Opus is only half the setup.

In Claude Desktop, open the model menu next to the send button and select Opus 5.5.

Now open Effort. Anthropic currently offers Low, Medium, High, Extra high, and Max on Opus 5.5.

For routine work, lower effort can save usage. For a long-running coding task, Extra high is designed for deeper work. And for the hardest, correctness-critical tasks, Anthropic recommends Max.

There’s one important detail: with Opus 5.5, thinking is always on. The effort setting controls how much work Claude applies to the response.

So the practical setup for a demanding task is simple: Opus 5.5, then choose the effort level that matches the job.

Higher effort can mean better depth, but it also takes longer and uses more tokens.

That’s the configuration to remember: choose the model, then tune the effort.
