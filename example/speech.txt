Want to generate continuous motion for a 3D character or humanoid robot? This tutorial walks through NVIDIA MotionBricks, from installation to your first generated animation.

MotionBricks is not a text-to-video tool. It generates movement between recent character poses and target poses. The same runtime supports the SOMA human skeleton and the Unitree G1 robot.

Start with a supported Windows or Linux x86-64 machine and an NVIDIA GPU. NVIDIA’s tested demo setup uses an RTX 4090. The runtime depends on TensorRT, Warp, Newton, Git LFS, and uv.

Install Git LFS and uv, clone the official NVlabs repository, pull the large files, and synchronize the Python environment. The first launch builds a TensorRT plan, so allow a few minutes.

Now launch the Inbetweener demo. Select SOMA, choose a starting pose, add target poses, and press Generate. MotionBricks fills in the transition between them.

For a reusable interaction, open the Smart Primitive Editor. Define an interaction box, a pivot, and target poses. Then use the Scene Editor to place that primitive in a scene.

Finally, launch Scene Preview and load the scene. Walk toward the obstacle and watch the character generate a vault, duck-under, or sitting interaction.

The model generates the motion; your application decides the target. That distinction is the key to integrating MotionBricks into a real animation workflow.
