Kimi just released its newest flagship model, Kimi K3 — and this one is hard to ignore.

According to Moonshot AI, K3 is a 2.8 trillion parameter open model with native vision and a one-million-token context window.

But the interesting part is not just the number.

K3 is designed for long-horizon coding, knowledge work and reasoning, while Kimi is also pushing its agent capabilities and large-scale parallel workflows.

And there is a practical distinction here.

Kimi's lineup separates the flagship K3 from coding-focused options such as Kimi for Coding, which currently uses K2.8 Preview, plus the faster K2.7 Code HighSpeed edition.

So if you're choosing a Kimi model, the question isn't simply which one is newest.

It's which tool fits the job: frontier general reasoning, dedicated coding, or high-speed development.

K3 is the flagship. The rest of the lineup is about choosing the right tool for the job.
