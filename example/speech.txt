In this tutorial, we’ll install NVIDIA Nemotron 3 Nano locally on Windows, using llama dot cpp, with no dedicated GPU required for the CPU-only route.

We’ll use NVIDIA’s official Nemotron 3 Nano 4B GGUF repository and the Q4 K M quantization. This is the Nano model, not Nemotron Super or Ultra. Performance depends on your CPU, available RAM, and context size, so don’t expect every computer to run it at the same speed.

First, open Windows Terminal or PowerShell. Install the packaged llama dot cpp build with this command: winget install llama dot cpp. If Windows asks you to accept source terms, review and confirm them. When installation finishes, close the terminal and open a new PowerShell window so the updated command path is loaded.

Now start the model directly from its official Hugging Face repository. Run: llama serve, then the Hugging Face option, followed by nvidia slash NVIDIA Nemotron 3 Nano 4B GGUF, colon Q4 underscore K underscore M. The complete command is shown on screen, so you can pause and copy it.

On first launch, llama dot cpp downloads the model files and stores them in its own cache. You do not need to invent a local model path for this method. Allow the download to finish before testing. The model file can be several gigabytes, so make sure you have enough free disk space and a stable connection.

When the server reports that it is listening, open your browser and go to localhost colon 8080. The local web interface should load. Enter a simple prompt and submit it. The first response may take longer while the model loads into memory.

If you prefer to keep a GGUF file in a folder you choose, download a compatible file from the official model repository and use the local server executable with the full path to that file. For example, a file saved in C colon backslash AI backslash Models would be referenced as C colon backslash AI backslash Models backslash your-model-file dot gguf. Replace that example with the exact filename you downloaded; do not copy the placeholder literally.

If the command is not recognized, reopen PowerShell and check that llama dot cpp installed successfully. If the model fails to load, check the repository name, quantization label, disk space, and available RAM. If localhost colon 8080 does not open, check the terminal for a startup error and make sure the server is still running.

That’s the basic setup: an official Nemotron 3 Nano GGUF model, launched locally through llama dot cpp, with a browser interface and no dedicated GPU required for the CPU route. Your actual speed and memory use will depend on your machine.
