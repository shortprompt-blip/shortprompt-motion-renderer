Want better gaming performance from your NVIDIA GPU? NVIDIA App gives you several useful controls, but the best settings depend on the game, your display and your priorities. Here is a practical setup you can use as a starting point.

First, open NVIDIA App and check your driver. Install a Game Ready Driver when you need support for a new release or a relevant fix, and read the release notes. Newer does not automatically mean faster in every game. Keep a stable version if everything is working well.

Open Graphics and look at Optimize. NVIDIA App can recommend game settings based on your hardware and display. Use the Quality and Performance balance as a starting point, then test the game. Do not assume the automatic preset is always best.

Next, separate Global Settings from Program Settings. Keep global driver options close to their defaults. Use a profile for each game when you need different behavior. A competitive shooter and a cinematic single-player game do not necessarily need the same settings. Avoid forcing maximum performance or low latency globally just because a guide says so.

For supported RTX games, DLSS Super Resolution can improve performance by rendering internally at a lower resolution and reconstructing the image. Start with Quality, then try Balanced or Performance if you need more FPS. Check sharpness and fine detail. DLAA is different: it improves anti-aliasing at native resolution and is not a performance upscaler.

Frame Generation can make supported games look smoother by adding generated frames. It does not increase the game's underlying simulation or input sampling rate. It is often more useful in single-player games with a stable base frame rate. For competitive play, compare responsiveness carefully. In supported games, enable NVIDIA Reflex in the game's own settings when low latency matters.

Now check your display. Set its native resolution and highest supported refresh rate in Windows and NVIDIA display settings. If your monitor supports G-SYNC or compatible variable refresh, enable it and test for tearing and stutter. Frame caps and V-Sync involve latency trade-offs, so do not copy a universal number without checking your own setup.

Use Alt plus Z to open the NVIDIA overlay. Performance statistics can help you monitor FPS, GPU usage and frame-time behavior. Keep only the capture and overlay features you actually use.

If available, Automatic GPU Tuning can scan and apply a performance profile. Treat it as an optional overclock: check temperatures, fan noise and stability, and revert if games crash or visual artifacts appear.

The most important step is testing. Choose a repeatable benchmark or game scene. Record average FPS, one-percent lows if available, frame times and temperatures. Change one setting, repeat the test under similar conditions, and keep it only if the improvement is consistent.

The baseline is simple: conservative global settings, per-game profiles, correct display refresh, DLSS and Frame Generation chosen by workload, Reflex when supported, and changes measured rather than guessed.
