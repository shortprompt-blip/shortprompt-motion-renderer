If you work with AI prompts, API responses, or structured notes, messy data can make your workflow harder to manage. In this video, I’ll show you how to clean up a JSON-style payload with the ShortPrompt LLM Data and JSON Formatter.

First, here’s the kind of input you might receive: a list of project details mixed with extra spaces and inconsistent formatting. Before sending data to an AI model, the goal is to make the structure clear and easy to reuse.

Open the LLM Data and JSON Formatter on ShortPrompt. The page gives you an input area for raw text or data, an output area, and a format selector. We’ll use a small example so you can follow every step.

Paste the sample notes into the input field. We have a project called Creator Dashboard, an example owner field, a status of in progress, and three tasks: fix the mobile layout, validate the JSON response, and update the documentation. The input counter shows how much text you’ve entered.

Now choose the output format. For this example, we want JSON. The structured result separates the project name, owner, status, and task list into clear key-value fields. That makes the information easier to inspect and easier to copy into a prompt or development workflow.

The important part is checking the result, not just clicking a button. Confirm that every task is present, the status is correct, and the output still represents the original information. Formatting can improve consistency, but it cannot decide whether your data is factually correct.

Next, compare the readable version with a compact version. Removing indentation and unnecessary whitespace can reduce the number of characters in the serialized text. That can be useful when you need a compact payload. But don’t assume fewer characters always means a dramatic reduction in model tokens. Tokenization differs by model, and whitespace changes can have a modest or variable effect. For reliable cost estimates, use the tokenizer or usage data for your actual model.

Once the output looks right, use Copy Formatted Data and paste it into your prompt, editor, or documentation. Always review sensitive or production data before sending it to any external AI service. The formatter is a preparation step, not a substitute for validation or security review.
