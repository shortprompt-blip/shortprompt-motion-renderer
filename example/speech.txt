We wanted to see if AI could build something more than a polished mockup.

So we gave GPT and Luna a simple task: build a real browser game from scratch.

We chose a small arcade game called Neon Escape.

The first step was the game loop and input state, so the browser could maintain the player position and update the game continuously.

Then we added procedural spawning and collision logic.

That means the obstacles are generated by the running JavaScript rather than being a pre-rendered animation.

Once the first build was ready, we opened it in Chromium and tested the actual interaction.

We then tuned the difficulty and connected the gameplay state to the score and energy systems.

Finally, we ran the complete browser loop again to verify that the game stayed playable.

The important part is that the output isn't a screenshot or a video pretending to be a game.

It's the HTML and JavaScript that actually run the game.

GPT created the initial structure, and Luna was used to iterate on the mechanics and final interaction.

From a prompt to a playable browser prototype.
