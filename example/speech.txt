Want better performance in Call of Duty Warzone? Before changing every graphics setting, use the NVIDIA tools that can actually tell you what is limiting your PC.

In this guide, we will combine the NVIDIA App, Project G-Assist, NVIDIA Reflex, and a repeatable performance test. The goal is not to promise a magic FPS boost. It is to identify the bottleneck, change one thing at a time, and keep the game responsive.

Start with the NVIDIA App. Open Drivers and check that your graphics driver is current for your exact GPU and device type. Desktop, notebook, and workstation drivers are not interchangeable in every case. Activision publishes separate recommended versions, including a workstation branch for Quadro cards. Do not install a driver just because its version number is newer: check the supported product list first.

Next, open Graphics and select Warzone under Program Settings. NVIDIA App can recommend game settings based on your GPU, CPU, and display. Treat this as a starting profile, not a benchmark result. Apply it, launch the game, and record a baseline before making more changes.

Now for the AI feature: Project G-Assist. It is a local assistant inside the NVIDIA ecosystem. On supported RTX systems, you can ask it to optimize a game's settings, analyze frame rate, inspect responsiveness, show performance metrics, and create charts for CPU and GPU usage. For example, ask: “Analyze Warzone performance” or “Create a chart of GPU utilization and frame rate.”

There are important limits. G-Assist requires a GeForce RTX 20, 30, 40, or 50 series GPU with at least six gigabytes of VRAM, a supported NVIDIA driver, and a recent NVIDIA App. Voice commands require RTX 30 series or newer, and NVIDIA currently lists English as the supported language. A Quadro P620 or another non-RTX card cannot use this feature. The assistant is a diagnostic helper, not a guarantee that every recommendation will improve your game.

Inside Warzone, check NVIDIA Reflex Low Latency. When available, start with Enabled. Test Enabled plus Boost only if you have a reason to keep GPU clocks elevated; compare the result rather than assuming Boost is always faster. Reflex targets system latency, not raw average FPS.

DLSS is different: it is an AI upscaling feature for compatible RTX hardware and supported game builds. Warzone has had DLSS support, but menus and features can change between releases. Only enable it if the current graphics menu actually offers it. Compare image clarity and frame pacing at the resolution you play. Do not use frame generation figures as if they were the same as native rendered frames.

Now measure the result. Use the NVIDIA performance overlay or a tool such as FrameView to capture average FPS, one-percent lows, GPU utilization, GPU temperature, and latency where available. Run the same map or training area for the same amount of time. Keep resolution, FOV, and the test route unchanged. Change one setting, repeat the test, and compare.

If GPU usage stays near one hundred percent, you are probably GPU-limited in that scene. If GPU usage is low while frame rate is poor, investigate CPU limits, power settings, background tasks, or a frame cap. High temperatures alone do not prove thermal throttling: check clock speed, power limits, and whether performance falls as the system heats up.

Finally, let Warzone finish shader preloading after a driver or game update. Activision warns that leaving the main menu can interrupt the process and cause performance problems. Keep the system stable before chasing tiny setting changes.

The workflow is simple: update carefully, inspect with G-Assist if your RTX hardware qualifies, enable Reflex, use DLSS only when the game supports it, and verify every change with repeatable measurements.
