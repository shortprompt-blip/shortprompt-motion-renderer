Problem 01 · Echo

Are you monitoring
through speakers?

Speaker audio can enter the microphone again and return to the stream.

SIGNAL PATH · EXPLANATORY RECONSTRUCTION
OBS audio → Speakers
Speakers → Microphone
Echo returns to stream
Fix 01 · Monitoring

Use headphones.
Check Monitor Off.

OBS · ADVANCED AUDIO PROPERTIES
Microphone Monitor Off
Desktop Audio Monitor Off
Monitoring Device Your headphones

Illustrative OBS layout. Use other monitoring modes only when your workflow requires them; avoid routing the same signal twice.

Problem 02 · Double audio

One microphone.
One active input.

A Global Mic/Aux device
B Separate Audio Input Capture
Both active? You may capture the mic twice.

Check Settings → Audio and your scene sources. Keep one intended input active, then record a test.

Problem 03 · Lip sync

Adjust the Sync Offset
in milliseconds.

ADVANCED AUDIO PROPERTIES · EXAMPLE
Microphone +120 ms
Capture Card 0 ms

+120 ms is illustrative only, not a universal setting. Record a clap, review playback, then adjust the source that is early or late in small steps.
