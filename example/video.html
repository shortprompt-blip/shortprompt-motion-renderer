04 / Reflex + DLSS

Latency and
upscaling differ.

Reflex reduces system latency. DLSS reconstructs the image at a lower render resolution on compatible RTX hardware.
Only enable DLSS if the current Warzone graphics menu offers it. Feature availability can change by game build.

06 / Find the limit

Read the data.
Not the guess.

GPU saturation, low GPU utilization, clocks and thermal trends point to different causes.
High temperature alone does not prove throttling. Check whether clocks or performance fall as the system heats up.
Diagnostic decision treeInterpretation
GPU near 100%

Likely GPU-limited in this scene. Reduce GPU-heavy settings or render resolution, then retest.

GPU load is low

Investigate CPU limits, power mode, background tasks, frame caps or an engine bottleneck.

Clock drops with heat

Check thermal and power limits over time. Temperature by itself is not enough.

After an update

Let shader preloading finish. Leaving the main menu can interrupt it.
