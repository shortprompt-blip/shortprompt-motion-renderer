HACK 01 / 07
Build a better prompt.
Use Microsoft's four-part prompt framework.
01 / GOALWhat do you want done?
02 / CONTEXTWho is it for and why?
03 / SOURCEWhich file or information?
04 / EXPECTATIONSFormat, tone and length.
PROMPT
Summarize this report for a beginner. Use only the attached file. Give me 5 bullets and 3 actions.
HACK 02 / 07
Upload a real file.
Ask Copilot to work directly from the material you provide.
PDFQuarterly_Report.pdf
Attached source
XLSXSales_Data.xlsx
Spreadsheet
ASK: Extract the 3 most important findings, quote the relevant figures, and list anything uncertain.
Supported formats and upload limits depend on the Copilot experience and account.
HACK 03 / 07
Refine. Don't restart.
Use short follow-up instructions to improve the first result.
FIRST ANSWER
A long summary with too much detail…
FOLLOW-UP 1
Make it 50% shorter.
FOLLOW-UP 2
Turn the key points into a checklist.
FOLLOW-UP 3
Show what is missing or unclear.
HACK 04 / 07
Use Search mode.
When you need up-to-date information from the web.
SEARCH REQUEST
Compare the latest official Copilot feature updates. Include publication dates and source links.
RESULT
Current web information + citations to inspect.
Citations are a starting point. Open the sources and verify important claims.
HACK 05 / 07
Choose Think Deeper.
For complex questions that need a more considered response.
QUICK RESPONSESimple, direct questions.
THINK DEEPERComplex trade-offs and problem solving.
Conversation modes vary by account, region and availability.
HACK 06 / 07
Specify the output.
Tell Copilot exactly how the answer should look.
Audience: new employees
Tone: friendly and clear
Format: numbered checklist
Length: under 200 words
One precise outcome beats a vague request.
HACK 07 / 07
Ground it in a source.
Reduce guesswork by pointing to the exact material.
SOURCE CONTROL
Use only the attached policy document. If the answer isn't in the file, say you can't find it.
Then ask Copilot to show the section that supports its answer.
