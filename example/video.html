01 · REQUIREMENTS

Check the machine first

The official runtime uses TensorRT and an NVIDIA GPU. NVIDIA reports testing the demos on Windows and Linux x86-64 with an RTX 4090.

02 · INSTALL

Clone the official repo

Pull the large Git LFS assets and let uv install the pinned Python environment.

TERMINAL · RECONSTRUCTED
git lfs install
git clone https://github.com/NVlabs/motionbricks.git
cd motionbricks
git lfs pull
uv sync
INSTALL
03 · FIRST GENERATION

Open the Inbetweener

Start with SOMA, place target poses in the viewer, and generate the motion between them.

01Launch: uv run python -m app.inbetweener_demo --model soma
02Select the SOMA character
03Choose the Start pose
04Add and position target poses
05Press Generate and inspect the transition
INBETWEENER
04 · HOW IT WORKS

Four context poses.
Up to four targets.

The model reads recent motion and the target poses. Your application decides the goal; MotionBricks generates the transition.

ContextFour recent poses
MotionBricksGenerates transition
Target1–4 goal poses
POSES
05 · REUSABLE INTERACTIONS

Build a Smart Primitive

Define the interaction box, pivot and target-pose hierarchy in the Smart Primitive Editor.

01Launch: uv run python -m app.smart_primitive_editor
02Create an Interaction box
03Add a Pivot node
04Add Entry and target poses
05Save the reusable primitive
PRIMITIVE
06 · PLAY A SCENE

Assemble and preview

Use the Scene Editor to place primitives, then run Scene Preview and test the interaction.

TERMINAL · RECONSTRUCTED
uv run python -m app.scene_editor

uv run python -m app.scene_preview \
  --scene assets/scenes/soma_gym.scene.json

# Try the Unitree G1 scene:
uv run python -m app.scene_preview \
  --scene assets/scenes/g1_gym.scene.json
