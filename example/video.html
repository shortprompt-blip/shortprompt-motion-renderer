01 / Choose the right model

Use the official Nano 4B GGUF

GGUF is the model format used in this llama.cpp workflow. The Q4_K_M variant reduces storage and memory demands compared with higher-precision versions.

Official NVIDIA repoQ4_K_M

Actual speed depends on CPU, RAM, context size and system load.

02 / Install llama.cpp

Open PowerShell

Install the packaged Windows build with WinGet.

Windows Terminal · PowerShell
PS C:\Users\You> winget install llama.cpp

03 / Download and launch

Start the official Q4_K_M model

Run the exact command from NVIDIA’s model card. On first launch, llama.cpp downloads and caches the model.

FIRST RUN

Wait for the download and model loading to finish. Don’t close the terminal while the server is running.

PowerShell · launch command
PS C:\Users\You> llama serve -hf nvidia/NVIDIA-Nemotron-3-Nano-4B-GGUF:Q4_K_M
No manually invented model path needed for this method

05 / Optional: use your own GGUF path

Keep the model in a custom folder

If you downloaded a compatible GGUF file yourself, use the local server executable and its full path.

Example path only

C:\AI\Models\your-model-file.gguf
Example command pattern
# Replace the placeholder with your actual file llama-server.exe -m "C:\AI\Models\your-model-file.gguf" -c 2048

Do not copy the placeholder filename literally.
