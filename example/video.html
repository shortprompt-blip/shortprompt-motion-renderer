02 · ENVIRONMENT

Prepare NeMo Speech

The documented vLLM path uses Python 3.13, vLLM 0.32.0 and NVIDIA NeMo Speech.

TERMINAL · RECONSTRUCTED
git clone https://github.com/NVIDIA-NeMo/Speech.git
cd Speech
uv venv --python 3.13 .venv
UV_PROJECT_ENVIRONMENT=$PWD/.venv uv sync --extra asr --extra vllm --locked --no-install-project
uv pip install --python .venv/bin/python --no-deps -e .
ENVIRONMENT
03 · MODEL CHECKPOINT

Download the weights

Keep the checkpoint variant aligned with your GPU and the matching model-card profile.

TERMINAL · RECONSTRUCTED
source .venv/bin/activate
hf download nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B \
  --local-dir ./NVIDIA-Nemotron-3.5-Transcribe-30B-A4B
CHECKPOINT
04 · SERVE THE MODEL

Launch vLLM

The full NVIDIA launch profile enables the speech plugin, audio limits and timestamp middleware.

01Set VLLM_PLUGINS=nemo_speechlm
02Set audio decode limit to 3600 seconds
03Enable the V1 runner for CTC word timestamps
04Run vLLM 0.32.0 with the BF16 H100 profile
05Expose the OpenAI-compatible API on port 8000
SERVER
05 · SEND AUDIO

One request.
One transcript.

Base64-encode a WAV file and send it with an explicit transcription instruction.

PYTHON · EXAMPLE
client = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="EMPTY")

response = client.chat.completions.create(
  model="nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B",
  messages=[{"role":"user","content":[
    {"type":"text","text":"Transcribe the following audio."},
    {"type":"audio_url","audio_url":{"url": audio_data_url}}
  ]}],
  temperature=0,
  extra_body={"chat_template_kwargs":{"enable_thinking":False}}
)
REQUEST
